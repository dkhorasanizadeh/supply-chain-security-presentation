# Supply-chain security presentation and demo

- **[slides/](slides/)** — presentation slides, assets, and speaker notes.
- **[demo/](demo/)** — runnable Kubernetes demo and its documentation.

Open `slides/index.html` in a browser to view the presentation.
Press **N** while viewing the slides to open the speaker notes.

Run demo commands from the `demo/` directory. See **[demo/README.md](demo/README.md)**
for setup instructions and **[demo/docs/DEMO.md](demo/docs/DEMO.md)** for the full walkthrough.
